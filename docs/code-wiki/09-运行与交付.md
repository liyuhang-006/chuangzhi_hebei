## 9.3 打开原型（已验证）

### 步骤

```bash
# 1. 解压（建议放到临时目录，避免污染仓库）
mkdir -p /tmp/prototype
unzip -o "/workspace/河北三期原型.zip" -d /tmp/prototype

# 2. 进入原型目录
cd /tmp/prototype/河北三期原型

# 3. 启动静态服务器
python3 -m http.server 8000

# 4. 浏览器访问
#    http://localhost:8000/start.html
```

也可以直接打开 `start.html`，但部分浏览器对 `file://` 下的脚本/资源加载有限制，推荐使用本地 HTTP 服务。

## 9.7 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 打开 HTML 空白 | `file://` 限制或路径含中文 | 用 `python3 -m http.server` 起服务 |
| 页面只有框架没有内容 | 图片未解压完整 | 重新完整解压 zip |
| 中文乱码 | 编辑器编码不是 UTF-8 | 以 UTF-8 打开 |
| 图片缺失 | 只解压了 HTML | 保留 `images/`、`files/`、`resources/` |
| 字体样式异常 | Google Fonts 被内网拦截 | 不影响布局，可忽略 |
| 文档只有指针 | 未拉取 LFS | `git lfs pull` |
| PDF 复制不出文字 | 扫描件无文字层 | OCR 或索取可检索版 |
| 原型页面列表打不开 | 未用 `start.html` | 从 `start.html` 进入 Player |
| 录音无法播放 | 编码/播放器不支持 | 用 VLC/PotPlayer；或先转码 |
