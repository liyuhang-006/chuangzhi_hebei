# 01 · 项目概览

## 1.1 项目背景

- 容量预警分析系统平台于 **2021 年**完成二期建设，基于动环系统实现全省站址电源和蓄电池专项管理，并创新性实现**批量远程放电**，替代人工现场核对性放电。
- 截至 **2022 年底**，平台已具备三项业务信息化能力：
  1. **有效评估梳理数据**：在电池管理视角梳理站上电源、电池设备及其连接映射关系，评估关键性能数据质量，推动不合理数据闭环改善。
  2. **实现远程自动放电**：激活动环对开关电源的遥调遥控能力，实现电池批量远程放电，提升后备时长数据准确性，并对锂电池进行安全监控与管理。
  3. **技术服务指导**：基于远程放电数据识别电池充放电环境隐患，解决电池因外部因素导致的可放电能力不达标问题。
- 本期项目在二期基础上扩建，目标是推动"采集、评估、分析、整改、整改效果评估"的自动化闭环。

## 1.2 建设目标

需求确认表给出的目标表述为：

> 利用现有资源和能力推动数据采集、评估、分析、整改以及整改效果评估的自动化闭环管理，实现站址电源系统常态化可持续运营改善，达到**分析算法自动化、整改组织流程化、数据管理平台化、稽核验证可视化**。

可拆解为四条主线：

| 主线 | 目标 | 对应能力 |
| --- | --- | --- |
| 数据可信 | 找到"账实不符、数据取不到、数据失真"的设备 | 资源准确性评定、性能质量评估、设备映射评定、动态数据评定 |
| 运营可行 | 找到"可遥调、可放电、可削峰填谷"的站址 | 遥调能力评定、运营池、远程放电、削峰填谷 |
| 收益可核 | 算清"省了多少钱、达成率如何" | 收益测算、实际收益评定、收益看板、电价设置 |
| 过程可管 | 权限、日志、导出、任务全过程可追溯 | 角色权限、平台日志、导出管理 |

## 1.3 项目范围

### 范围内

- 设备数据质量评定：资源准确性、信号量通道合理性（性能质量）、设备映射、协议库、遥调能力、动态数据、动环通道质量。
- 电池健康度智能评估：电池衰减情况分析。
- 能量运营效果稽核：运营站址池管理、能量运营监测、能量运营分析。
- 电池运营作业：远程放电管理/监控/历史、削峰填谷管理/监控/历史。
- 运行质量管理：机房运行、供备电能力、电表运行、空调运行评估。
- 节费效果管理：收益测算、实际收益评定、收益看板、电价设置。
- 平台支撑：站址/虚拟集合、机房与设备管理、用户/角色/日志、批量遥调、查询性能、查询告警、导出管理。

### 范围外 / 未启动

- 数字驱动电池作业管理（作业计划、自动督办、稽核、统计分析）——优先级"低"，状态"未启动"。
- 统计报表、隐患分析、平台管理、站址管理——"待客户确认"。
- 统计报表等未在原型中单独建页的能力。

### 边界说明

- 本仓库只包含需求、原型、合同与确认表，不包含平台源代码、数据库脚本、接口实现或部署编排文件。
- 合同技术规范书为 152 页扫描件，无法从仓库直接检索条文；涉及商务、验收、SLA 的最终口径应以合同原件为准。

## 1.4 用户角色

资源准确性评定章节给出了较完整的角色定义（需求文档 4.1.1）：

| 角色 | 职责 | 典型操作 |
| --- | --- | --- |
| 超级管理员 | 关键配置与权限管理 | 设置对比项、配置按钮权限、维护导出上限 |
| 资源数据维护人员 | 维护综资/现场数据 | 下载模板、导入资源、查看导入异常 |
| 资源核查人员 | 查看评定结果、定位差异 | 多维度查询、查看站房汇总/数量评估/设备评估 |
| 整改责任人员 | 线下整改与复核 | 查看差异清单、整改后触发二次核验 |
| 管理查看人员 | 掌握整体质量与治理成效 | 查看汇总、导出结果、跟踪进展 |

其他模块隐含角色：省/地市运维人员（接口质量）、运营人员（放电/削峰填谷/运营池）、协议管理员（协议库）、系统管理员（用户/角色/日志）。

权限模型要求支持**页面权限、按钮权限、数据权限**三层，数据权限按省/地市/区县划分。

| 完全整治 | 在基础整治之上，按协议库标准判断信号量完整性 |
| 资源准确 | 资源准确性评定的合格结论 |

## 1.8 关键约束

- **稳定性**：7×24 小时稳定运行。
- **国产化**：数据库支持国产化系统；服务器支持 Linux 国产操作系统。
- **浏览器**：兼容 IE9 以上，支持 HTML5。
- **响应**：指令 ≤ 5 秒，复杂分析 ≤ 10 秒，输入界面打开 ≤ 5 秒；登录 ≤ 0.5 秒；页面数据加载 ≤ 2 秒，大数据页面 ≤ 5 秒。
- **安全**：满足集团二次安防漏洞扫描与通信安全技术规范。
- **性能**：1 万个站房的数量对比与设备字段对比需在 20 分钟内跑完。
- **导出**：1 万条以内 0.5 秒开始下载；1–5 万条 ≤ 10 秒；5–10 万条 ≤ 2 分钟；10–50 万条 ≤ 5 分钟。
- **分辨率**：适配 1280×720、1920×1080、2560×1440、2160×1440。
- **部署差异**：内网环境隐藏"省"查询，默认项目所在省；河北隐藏"所属动环"字段。

> 以上为需求约束，不是仓库中已验证的实现能力。
