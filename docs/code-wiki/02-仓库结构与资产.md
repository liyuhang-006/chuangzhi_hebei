## 2.4 原型包结构

解压 `河北三期原型.zip` 后得到 `河北三期原型/`：

```text
河北三期原型/
├── start.html                 # 原型启动页（推荐入口）
├── index.html                 # 另一入口
├── start_c_1.html
├── start_with_pages.html
├── 平台入口.html              # 一级菜单页（另有 43 个页面）
├── data/
│   ├── document.js            # Axure 页面树、配置、全局样式
│   └── styles.css
├── files/
│   └── <页面名>/
│       ├── data.js            # 该页的 Axure 控件/交互数据
│       └── styles.css
├── images/
│   └── <页面名>/              # 页面截图与图标（约 6.1 MB）
├── resources/
│   ├── css/  scripts/  chrome/ # Axure 运行时
│   └── ...
└── plugins/
    └── sitemap/ page_notes/ debug/ recordplay/
```

要点：

- 44 个业务页面均有对应的 `files/<页面名>/data.js`，无缺失。
- 页面主体大量使用**整页截图**（如 `images/运营池/u873.png`，1716×835），因此阅读原型以看图为主，文字控件较少。
- Axure 运行时依赖 `resources/scripts/jquery-*.js`、`axure/*`，离线可用，无需联网（仅字体 CSS 引用 Google Fonts，缺失不影响布局）。
- 原型包内页面树由 `data/document.js` 的 `sitemap.rootNodes` 定义，共 13 个一级节点、44 个页面。

## 2.6 大文件与 Git LFS

`.gitattributes` 对以下类型启用 LFS：

```text
*.zip filter=lfs diff=lfs merge=lfs -text
*.rp filter=lfs diff=lfs merge=lfs -text
*.docx filter=lfs diff=lfs merge=lfs -text
*.xlsx filter=lfs diff=lfs merge=lfs -text
*.m4a filter=lfs diff=lfs merge=lfs -text
*.pdf filter=lfs diff=lfs merge=lfs -text
```

克隆仓库前需安装 `git-lfs`，否则拿到的可能是指针文件。当前工作区中的文件已是实际内容（可直接读取）。

## 2.7 没有源代码

仓库中不存在：

- 后端工程（Java/Go/Python/Node 等）；
- 前端工程（Vue/React 等）；
- 数据库 DDL、表结构、初始化数据；
- 接口定义（OpenAPI/Swagger/Proto）；
- CI/CD、Dockerfile、K8s 清单、部署脚本；
- 单元测试/集成测试。

因此"项目运行方式"只能覆盖**原型查看**与**文档阅读**，不能覆盖业务系统启动。详见 [09-运行与交付.md](09-运行与交付.md)。
