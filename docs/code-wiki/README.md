> 本 Wiki 基于仓库内全部可读资产（需求文档、Axure 原型、需求确认表、导出模板、合同技术规范书、会议录音等）逆向整理，用于帮助产品、研发、测试、交付人员快速理解项目全貌。

## 一、先读这一条

**本仓库不是应用源代码仓库，而是"需求 + 原型 + 合同"资产库。**

仓库内没有 `src/`、`package.json`、`pom.xml`、数据库脚本或可执行服务，因此：

- 不存在可直接编译、启动的业务系统；
- 不存在真实的类、方法、API 实现；
- 本 Wiki 中的"关键类/函数"章节，按**领域对象 + 业务规则 + 算法口径 + 伪代码**的方式组织，名称是分析抽象，**不是仓库中的代码符号**；
- 所有"实现状态"来自需求确认表与原型，不代表代码已交付。

真正可"运行"的只有 Axure 静态原型，打开方式见 [09-运行与交付.md](09-运行与交付.md)。

## 三、项目一句话

在容量预警分析系统二期基础上，建设一套面向河北移动自有基站机房的**电池与电源数据质量评定、远程放电/削峰填谷运营、节费收益稽核**平台，实现"数据采集 → 评估 → 整改 → 运营 → 效果稽核"的自动化闭环。
